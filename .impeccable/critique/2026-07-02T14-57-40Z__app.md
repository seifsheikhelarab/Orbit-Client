## Overall Impression

Orbit's design system document (DESIGN.md) is strong and well-articulated. The codebase doesn't fully implement it. Three P0 issues — card radius/shadow, pipeline chart colors, sidebar accent bar — directly contradict the documented system. The codebase has multiple "pre-design-system" artifacts (PipelineFunnelChart independent colors, Card.tsx 32px radius, staggered animation patterns) that never got reconciled with the formal system. The brand promise of "calm control" is undermined by an over-animated loading fallback and 1.5-second staggered reveals. The bones are good; the biggest opportunity is implementation fidelity.

## Priority Issues

### [P0] Card.tsx radius + shadow violates DESIGN.md
- **What**: Card.tsx:17 uses `rounded-[2rem]` (32px) vs DESIGN.md spec of 24px (`rounded-xl`). Also has `shadow-sm` at rest violating Flat-by-Default Rule.
- **Why**: The design system promises one thing and delivers another. Users developing UI against the system will produce inconsistent spacing.
- **Fix**: Change to `rounded-2xl` (24px). Remove shadow from default variant, move to elevated variant only.
- **Suggested command**: `$impeccable polish components/ui/card`

### [P0] PipelineFunnelChart hardcoded colors don't match system tokens
- **What**: PipelineFunnelChart.tsx:78-85 hardcodes `#a8009a` (Applied), `#5c6000` (Interview), `#56404f` (Closed) — completely separate from the system status tokens (`#4f46e5`, `#f59e0b`, `#64748b`). Detector confirmed `#dcbed1` drift across both chart components.
- **Why**: Same data renders in different colors depending which chart the user sees. Destroys the semantic color language.
- **Fix**: Import and use `STATUS_DASHBOARD_COLORS` from the status token module. Delete local `getStatusColor` map.
- **Suggested command**: `$impeccable colorize components/dashboard`

### [P0] Sidebar active-state accent bar is banned side-stripe
- **What**: Sidebar.tsx:47 uses `w-1 h-6 bg-accent rounded-r-full` as a left accent stripe on active NavItems.
- **Why**: DIRECT violation of DESIGN.md's "Don't use border-left > 1px as a colored accent stripe" and the impeccable absolute ban on side-stripe borders. The active state already has `bg-on-primary/10` and `text-accent scale-110` — the stripe adds nothing.
- **Fix**: Remove the absolute-positioned stripe div. The background tint and icon color shift already differentiate active state.
- **Suggested command**: `$impeccable polish components/layout/sidebar`

### [P1] Text sizes below 11px (8px, 9px, 10px)
- **What**: DashboardOverview.tsx uses `text-[8px]` (bar chart dates line 310), `text-[9px]` (activity timestamps line 342), `text-[10px]` (trend labels line 240).
- **Why**: DESIGN.md Density Rule: "Nothing goes below 11px." 8px text fails WCAG SC 1.4.4 resize text.
- **Fix**: Remap to `text-label-sm` (11px) / `text-label-md` (12px). Shorten copy if needed. Tooltip for overflow.
- **Suggested command**: `$impeccable polish features/dashboard`

### [P1] Loading fallback over-animated
- **What**: App.tsx:38-62 uses 4 simultaneous animation types: rotating pulse grid, scanning telemetry line, pulsing text, 3 bouncing dots.
- **Why**: "Calm control" brand promise violated. For stressed job seekers, this amplifies urgency and anxiety instead of steadying.
- **Fix**: Replace with single subtle animation (logo fade-in + thin loading bar). Remove bounce, scan, multi-element pulse.
- **Suggested command**: `$impeccable quiet app`

### [P2] Staggered entry animations too long
- **What**: DashboardOverview.tsx chains animation delays from 100ms to 1500ms (stat cards → charts → secondary insights).
- **Why**: Perceived performance suffers — content reveals in pieces over 1.5s instead of appearing at once.
- **Fix**: Cut all animation delays to ≤300ms max. Or remove staggered delays since TanStack Query loading states handle sequencing.
- **Suggested command**: `$impeccable animate features/dashboard`

### [P2] Hover shadows on non-interactive containers
- **What**: PipelineFunnelChart.tsx:20 and SankeyChart.tsx:139 have `hover:shadow-2xl transition-all` on divs that aren't clickable (no pointer cursor, no onClick).
- **Why**: False affordance — users click expecting interaction. Shadows are for interactive states only per DESIGN.md.
- **Fix**: Remove hover shadows from chart wrappers. Add drill-down if interaction is planned; otherwise remove the promise.
- **Suggested command**: `$impeccable polish components/dashboard`

### [P2] Eyebrow labels on every section
- **What**: DashboardOverview.tsx uses `text-[10px] font-bold uppercase tracking-wider` on stat card labels (line 232), chart headers (SankeyChart.tsx:141), activity header (line 297).
- **Why**: DESIGN.md explicitly says "Don't use uppercase tracked text as a default eyebrow above every section." This is the 2023 AI grammar tell.
- **Fix**: Use sentence-case for section headers. Reserve uppercase tracked for badge/status contexts.
- **Suggested command**: `$impeccable quieter app`
