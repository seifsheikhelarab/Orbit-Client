# Design Critique: Orbit Client

**Method**: dual-agent (A: design review · B: detector scan)

## Anti-Patterns Verdict

**Verdict: Conditional PASS — mid-tier tells present.**

Orbit avoids the bottom-tier AI slop (no gradient text, no bounce animations, no numbered section markers, no hero-metric gradient accents). The component system is rigorous — CVA variants, consistent tokens, deliberate palette. This is engineered, not scaffolded.

**But the dossier theming layer is the tell.** Five specific patterns:

| Pattern | Location | Verdict |
|---------|----------|---------|
| Warm off-white bg (#fcf9f6) | index.css:38 | Distinctive but same family as cream/sand default |
| Floating blur blobs | Login.tsx:40-41 | Single most recognizable AI UI pattern |
| Scanline overlays + dossier glow | Sidebar.tsx:67-72, index.css:245-299 | Decorative noise, not functional |
| "Ref: XXXX" / "Purge Data" copy | KanbanCard.tsx:147,191 | Cosplay, not user language |
| Animated counters on all stats | DashboardOverview.tsx:262-265 | Hero-metric template variant |

Detector scan: 146 findings across 6 rules. ~60 false positives (CV PDF templates + StickerSheet). Real hits: text-[10px] as label token (~70 instances), border-l-4 side-stripes on 3 components, 25+ animations with no prefers-reduced-motion fallback.

## Priority Issues

### P0 — Error Recovery Is Absent
ApplicationsPage.tsx:218-226 — Dead-end error with no retry, no context, no support link.

### P1 — Dossier Theming Over Decoration Budget
Scanlines, blobs, glow, "Ref: XXXX", "Purge Data" push from distinctive to themed.

### P2 — No Back Navigation on Nested Pages
No breadcrumb trail or back button on application detail/edit pages.

### P3 — Missing prefers-reduced-motion on 25+ Animations
Only 1 of 26 keyframe animations handles reduced motion.

### P3 — text-[10px] Systemic Token Gap
~70 instances across codebase with no design token.

## Persona Red Flags

### Sam (Accessibility)
- No skip-to-content link (8+ sidebar tabs)
- Kanban drag is mouse-only (no KeyboardSensor)
- Manual onMouseDown/Up class toggling on kanban cards

### Riley (Stress Tester)
- Error dead-end with no retry
- No undo on status changes after success
- 25+ animations without reduced-motion handling

### Alex (Power User)
- Column visibility not persisted across refresh
- No kanban keyboard navigation
- Dashboard empty when <20 applications

## Strengths
1. Filter/kanban/table trifecta with progressive disclosure
2. Component system rigor (CVA variants, central status config)
3. Power user features (keyboard shortcuts, bulk ops, drag-and-drop)
